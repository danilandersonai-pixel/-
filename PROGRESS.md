## Блокеры

1. **`expo-doctor`: 2 проверки не запускаются в облачной среде.** Им нужен доступ к api.expo.dev и
   reactnative.directory, а прокси среды их не пускает. На компьютере с интернетом команда отработает полностью.
   Совместимость версий пакетов обеспечена установкой через `npx expo install` (офлайн-список версий SDK 57).
2. **Приложение не запускалось на настоящем телефоне** — у меня нет устройства. Что проверено вместо этого:
   сборка бандлов iOS и Android, все запросы к базе на настоящем SQLite (тесты), каждый экран — сценариями
   в браузере в светлой и тёмной теме. Первый запуск в Expo Go — главная непроверенная часть.
3. Выбор файла копии в превью проверен в браузере, но в окне артефакта Claude он может быть запрещён
   настройками безопасности. На телефоне выбор файла — системный, это не затрагивает.
4. При публикации артефакта появляется предупреждение о «ссылке на скачивание». Это код библиотеки внутри бандла,
   само приложение в браузере ничего не скачивает. На работу не влияет.

## Как проверить на телефоне

**Подготовка (один раз):**
1. Установите на телефон **Expo Go** (App Store / Google Play).
2. На компьютере с Node.js 22: `git clone https://github.com/danilandersonai-pixel/-.git sport-tracker`,
   затем `cd sport-tracker`, `npm install`, `npx expo start`.
3. Отсканируйте QR-код (iPhone — камерой, Android — в Expo Go). Телефон и компьютер — в одной Wi-Fi сети,
   иначе `npx expo start --tunnel`.

**Быстрый путь:** Настройки → «Заполнить примером» → «Добавить». Появятся 3 вымышленных подопечных с историей.

**По этапам:**
- **Тренер в отчёте.** Настройки → «Тренер» → имя, телефон, мессенджер. Карточка → «Замеры» → «PDF-отчёт» →
  «Свои даты» → введите «с» и «по». В шапке отчёта — строка «Тренер: …».
- **Замеры.** Карточка Анны → «Замеры»: вверху цель «Жир · 20 %» с полосой пути и прогнозом — нажмите, чтобы изменить.
  «Только вес» → введите вес → «Готово» — в списке новый замер. «Сравнить» → выберите «Было» и «Стало».
  «Графики и фото» → «Фото до/после» → «Шторка» → ведите пальцем по фото (нужны два фото одного ракурса).
- **Связь и таблица.** Карточка Анны → под именем кнопки «Позвонить» и «WhatsApp» (откроют телефон и WhatsApp).
  Вкладка «Замеры» → «Выгрузить в Excel (CSV)» → отправьте файл себе и откройте в Excel или Google Таблицах.
- **Оформление.** Приложение тёмное с салатовым, если телефон в тёмной теме. Настройки → «Оформление» → «Светлая» —
  приложение сразу станет светлым, даже если телефон тёмный; выбор сохранится после перезапуска. На рабочем столе
  телефона — новая иконка (гриф и линия роста). В Expo Go иконка и заставка будут от Expo Go: свои видны только
  в собранном приложении.
- **Сегодня.** После «Заполнить примером» вверху списка — блок «Сегодня»: тренировка Анны в 19:00, день рождения
  Игоря через 3 дня, Ольге пора сделать замер. Нажмите на строку Ольги — откроется её карточка на вкладке «Замеры»
  с напоминанием. Начните поиск — блок спрячется.
- **Рекорды.** Карточка Игоря → «Тренировки» → «Личные рекорды»: жим лёжа, жим ногами, подтягивания.
  У тренировок с рекордом — кубок. Нажмите «Жим лёжа» → график расчётного максимума растёт, «?» объясняет формулу,
  внизу история с отметками «Рекорд». У Ольги «Гиперэкстензия» — упражнение без веса, там считаются повторы.
- **Каркас.** Три вкладки переключаются; включите тёмную тему в телефоне — приложение тоже станет тёмным.
- **Подопечные.** «+» → введите имя → «Далее: согласие» → «Подопечный согласен» → открылась карточка.
  Закройте приложение полностью и откройте снова — подопечный на месте. Поиск по фамилии и цифрам телефона.
  Профиль → «Перенести в архив» → он пропал из списка и появился в «Архив».
- **Замеры и калькулятор.** Карточка → «Замеры» → «Добавить первый замер»: мужчина, вес 70, рост 175,
  шея 38, талия 86 → «Посчитать». Должно быть: жир 17,7 %, жировая масса 12,4 кг, безжировая 57,6 кг, ИМТ 22,9.
  Нажмите «?» у любой плитки — появится объяснение.
- **Прогресс.** В карточке Анны (пример) → «Замеры» → «Графики и фото»: линия жира идёт вниз.
  «Добавить фото» → «Снять на камеру» — телефон спросит разрешение на камеру.
- **Тренировки.** Календарь → «Запланировать тренировку» → выберите подопечного → время, упражнение, подходы.
  В списке подопечных появится дата следующей тренировки. «Новая тренировка» → «Повторить прошлую».
- **Питание.** Карточка → «Питание» → «Задать цель по питанию» → калории и КБЖУ → строка
  «КБЖУ дают … ккал» и базовый обмен.
- **Экспорт.** Карточка Анны → «Замеры» → «PDF-отчёт для подопечного» → «Создать PDF и поделиться» —
  откроется системное меню, отправьте себе в мессенджер и откройте PDF.
- **Резервная копия.** Настройки → «Сохранить резервную копию» → сохраните файл `sport-tracker-backup-….zip` в «Файлы».
- **Восстановление.** Настройки → «Восстановить из копии» → «Выбрать файл копии» → выберите сохранённый ZIP.
  Приложение покажет, что добавится. Если всё уже на телефоне — «Всё уже на месте». Чтобы проверить по-настоящему:
  сохраните копию, переустановите Expo Go (или удалите приложение), восстановите — подопечные и фото вернутся.

## Итоговый отчёт

Сделано полное MVP приложения тренера по CLAUDE.md: подопечные с согласием на обработку данных о здоровье,
здоровье, замеры с калькулятором состава тела (5 формул, погрешности, объяснения), прогресс с графиками и фото,
тренировки с календарём, питание, PDF-отчёт, резервная копия, демо-данные. Всё сохраняется само при вводе,
работает без интернета, в светлой и тёмной теме. Код разделён: экраны — `app/`, запросы — `src/db/`,
расчёты — `src/lib/calc/`, тексты — `src/i18n/ru.ts`. 120 тестов, в том числе все контрольные примеры формул
и все функции работы с данными. Решения и их причины — в `DECISIONS.md`.

Что осталось непроверенным и требует внимания: запуск на настоящем телефоне; текст согласия — шаблон,
его стоит показать юристу.

## Итог дополнений (этапы 11–13)

- **Копия стала полной:** один ZIP-файл с данными и фото, восстановление с предпросмотром «Что изменится».
  Ничего не удаляется: из двух версий записи остаётся более новая. Старые JSON-копии тоже читаются.
  Попутно исправлено хранение путей к фото: на iPhone после обновления приложения старые пути перестали бы работать.
- **Блок «Сегодня»** на главном экране: тренировки дня, дни рождения, кому пора делать замер.
- **Личные рекорды:** лучший подход и расчётный максимум по каждому упражнению, графики, кубки у рекордных тренировок.
  Попутно найдена и исправлена ошибка демо-данных (вес снижался) и две неточности графиков.
