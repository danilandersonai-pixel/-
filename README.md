# -
Разработка спортивного приложения для отслеживания спортивных показателей, коммуникаций и др, разработка на ios и андроид 

## Спортивный Треккер

Приложение для персонального тренера: подопечные, замеры и калькулятор состава тела, тренировки, питание.
Подробное описание проекта и правила разработки — в [CLAUDE.md](CLAUDE.md).

## Что умеет

- Подопечные: поиск, архив, профиль, согласие на обработку данных о здоровье (152-ФЗ), звонок и WhatsApp/Telegram из карточки
- Здоровье: противопоказания, травмы, ограничения, анкета готовности к нагрузкам PAR-Q
- Замеры с подсказкой «где мерить» и калькулятор состава тела: % жира (ВМС США, Jackson–Pollock),
  жировая и безжировая масса, мышечная масса (Lee), ИМТ, FFMI — с методом, погрешностью и объяснением
- Прогресс: графики по датам, цель с прогнозом, сравнение любых двух замеров, фото «до/после» рядом или шторкой
- Тренировки: календарь, серии по дням недели, подходы, личные рекорды, таймер отдыха, абонементы, уведомления
- Питание: калории и КБЖУ, проверка цифр, базовый обмен
- PDF-отчёт за любой период, выгрузка в Excel (CSV), резервная копия с фото и восстановление
- Надёжность: всё сохраняется само, работает без интернета, корзина, напоминание о копии, вход по Face ID
- Блок «Сегодня» на главном экране, светлая и тёмная тема

Из каких файлов состоит приложение — в [docs/components.md](docs/components.md).

Живое демо в браузере: https://raw.githack.com/danilandersonai-pixel/-/main/docs/demo/index.html

## Как запустить

Нужен компьютер с [Node.js](https://nodejs.org) (LTS) и приложение **Expo Go** на телефоне.

```bash
npm install        # один раз после скачивания проекта
npx expo start     # запуск; отсканируйте QR-код телефоном
```

Телефон и компьютер должны быть в одной Wi-Fi сети. Если не подключается — `npx expo start --tunnel`.
