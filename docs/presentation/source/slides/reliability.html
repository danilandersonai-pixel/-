Надёжность

Здесь данные не теряются

Сохраняется само, при вводе — кнопки «Сохранить» нет

Работает без интернета

Ничего не удаляется насовсем: архив и корзина

Резервная копия — один ZIP-файл вместе с фото

Вход по Face ID, отпечатку или коду телефона

Данные только на телефоне: без аналитики и трекеров

Главная жалоба на приложения конкурентов — потеря данных, поэтому надёжность здесь главное требование. Всё сохраняется при вводе и работает без интернета. Удалённое можно вернуть из корзины. Копия — один файл с фото, её можно восстановить на новом телефоне. Данные никуда не отправляются.
